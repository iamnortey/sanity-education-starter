# Contributing

Thanks for your interest in contributing to Sanity Education Starter.

## Getting Started

```bash
git clone https://github.com/iamnortey/sanity-education-starter.git
cd sanity-education-starter
npm install
```

## Making Changes

1. Fork the repo and create a branch from `main`.
2. Make your changes. Keep PRs focused.
3. Open a pull request with a clear description.

## What We're Looking For

- New schema types for educational content
- Validation improvements
- Documentation clarifications

## Reporting Issues

Open an issue at [github.com/iamnortey/sanity-education-starter/issues](https://github.com/iamnortey/sanity-education-starter/issues).
